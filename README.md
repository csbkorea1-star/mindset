# 마음셋 2.0 · 3인 자동매칭 배포본

마음하나 1명과 지지자 2명이 자동매칭되어 5분간 익명 채팅합니다. 지지자는 채팅이 금지된 대기방에서 기다리며, 마음하나가 들어오면 먼저 기다린 지지자 2명과 매칭됩니다. 한 계정은 동시에 하나의 방 또는 대기열에만 참여할 수 있습니다.

기존 회원·가상 사례금·랭킹 데이터베이스를 유지합니다. 가족 초대방 사용자 화면은 제거했습니다. 기존 초대 관련 데이터베이스 테이블은 기존 데이터와의 호환성을 위해 유지합니다.

## 배포
GitHub 저장소에 이 ZIP 안의 파일과 폴더를 같은 경로로 업로드합니다. Render: Node / `npm install` / `npm start`. 기존 DATABASE_URL 환경변수는 변경하지 마세요. 기존 사이트에 적용하기 전에 별도 테스트 서비스를 이용하는 것이 안전합니다.

## 점검
세 계정으로 접속해 지지자 2명 대기 → 마음하나 입장 → 3인 채팅 → 사례금 → 랭킹을 확인하세요. 랭킹에서 5초 이상 스크롤을 유지하는지도 확인하세요. 실제 사례금 결제는 구현되어 있지 않으며 테스트용 가상 보상입니다.
