# 마음셋 · 가족 3인 무료 테스트 배포본

## 올릴 프로그램 파일은 세 개입니다

1. 저장소 첫 화면에 server.js, package.json을 함께 업로드합니다.
2. 저장소의 public 폴더 안에서 public/index.html을 업로드합니다.

server.js 안에 회원·저장소 코드를 모두 포함했으므로 accounts.js나 storage.js를 별도로 올리지 않아도 됩니다. 소스에는 데이터베이스 비밀번호가 들어 있지 않습니다.

## Render 설정과 배포 상태

기존 MAUMSET 서버는 무료 플랜을 유지합니다. 무료 maumset-family-test-db가 생성돼 있으며, 2026년 12월 10일에 만료됩니다. 장기 보존용이 아닌 가족 테스트용입니다. 유료 전환은 하지 않았습니다.

Render 환경변수의 Datastore URL 기능으로 같은 지역 데이터베이스의 Internal URL을 연결하고, 변수 이름이 DATABASE_URL인지 확인해야 합니다. 연결 주소에는 비밀번호가 있으므로 외부에 공유하지 마세요. 현재 확인된 배포 소스 25aaef5는 이전 프로그램입니다. 위 세 파일을 반영한 뒤 새 배포를 확인해야 합니다.

GitHub main 브랜치 업로드 시 자동 배포됩니다. 새 배포가 Live가 되면 사이트를 새로 열어 회원가입 화면이 나오는지 확인하세요. 초기 테이블은 시작 시 생성합니다.

## 가족 테스트

각자 회원가입 → 한 사람이 가족방 생성 → 두 사람에게 초대 링크 공유 → 마음하나 1명/위로해주기 2명 선택 → 5분 대화 → 마음하나 보상 선택 완료 → 수령자 가상 보상 알림/랭킹 확인 순서입니다.

회원가입에는 아이디·비밀번호·닉네임·성별·나이를 입력합니다. 같은 기기에서는 로그인 상태를 복원하고, 다른 기기는 아이디·비밀번호로 로그인합니다. 내 정보에서 비밀번호 확인 후 탈퇴할 수 있습니다. 성별·나이·아이디는 다른 참여자에게 공개하지 않습니다.

## 검사

Node.js 22.13 이상 24 버전에서 npm install, npm test, npm start를 사용합니다. 실제 로컬 HTTP·WebSocket과 SQLite를 사용한 회원·보상·동시 재요청·랭킹·알림·초대방 검사 및 화면 스크립트 검사를 통과했습니다. 배포용으로 코드를 합친 뒤에도 같은 검사를 다시 통과했습니다. 실제 Render Postgres 연결/테이블 생성과 휴대폰 최종 시험은 새 코드 배포 후 남아 있습니다.

Postgres 연결에는 DATABASE_URL을 사용하고 로컬 시험은 data/maumset.sqlite를 사용합니다. Render에서 저장소 설정이 없으면 임시 파일에 회원정보를 저장하지 않고 시작을 중단합니다.
